# Population density grids

The files in this directory are derived from **HYDE 3.2.1** (History Database of the Global Environment, baseline scenario) by Kees Klein Goldewijk et al., Utrecht University and PBL Netherlands Environmental Assessment Agency.

## Citation

Klein Goldewijk, K., Beusen, A., Doelman, J. & Stehfest, E. (2017). Anthropogenic land use estimates for the Holocene - HYDE 3.2. *Earth System Science Data* 9, 927-953. https://doi.org/10.5194/essd-9-927-2017

## Source

- Dataset: https://doi.org/10.17026/dans-25g-gez3 (DANS Data Station Archaeology, file `HYDE3_2_1-baseline.zip`, id 5490328; land area from `HYDE3_2_1-general_supplementary.zip`, id 5490327)
- Only the needed members are fetched with HTTP range requests from https://archaeology.datastations.nl/api/access/datafile/<id>
- HYDE 3.3 (https://doi.org/10.24416/UU01-67UHB4, CC BY 4.0) is served behind a browser proof-of-work challenge and could not be downloaded by a script.

## Processing

Generated by `scripts/build-population.mts` (`npm run data:population`).

1. Population counts `popc_<step>.asc` (5 arc-minute, 4320 x 2160) are summed into 1 degree cells (12 x 12 source cells each).
2. Density is that sum divided by the summed HYDE maximum land area `maxln_cr.asc` of the cell, in people per km2 of land. Cells without land area use the spherical cell area.
3. Encoding: Uint8 row-major 360x180, row 0 centred at 89.5N, column 0 centred at 179.5W. 0 = under 0.05 people per km2; 1..255 = log10 scale, density = 0.1 * 10^(5 * (code - 1) / 254) people per km2 of land, clamped to 0.1..10000.
4. Time steps (file year and HYDE step): -3000 (3000BC), -2000 (2000BC), -1000 (1000BC), 1 (0AD), 100 (100AD), 200 (200AD), 300 (300AD), 400 (400AD), 500 (500AD), 600 (600AD), 700 (700AD), 800 (800AD), 900 (900AD), 1000 (1000AD), 1100 (1100AD), 1200 (1200AD), 1300 (1300AD), 1400 (1400AD), 1500 (1500AD), 1600 (1600AD), 1700 (1700AD), 1750 (1750AD), 1800 (1800AD), 1850 (1850AD), 1900 (1900AD), 1950 (1950AD), 2000 (2000AD), 2017 (2017AD). HYDE 3.2.1 has no 500 BCE step and ends in 2017, which stands in for 2020.
